# WORDROP — 歴史改変シミュレーション

空に浮かぶ 100×100 タイルの箱庭の島に「単語」を投下して、歴史を書き換えるブラウザゲームです。
90年代のクォータービュー箱庭ゲーム風の見た目を、外部画像を使わずすべて Canvas のプロシージャル描画で表現しています。

## 遊び方

1. タイトルで **PUSH START BUTTON** → **日本史コース / 世界史コース** を選択
2. 右パネルの入力欄に15文字以内の単語を入れて（または下の単語カードをクリックして）**「歴史に投下」**
3. 10年後 → 50年後 → 200年後 の歴史の変化がログに流れ、文明パラメータと箱庭の島が変化します
4. 全3時代を生き延びると、2026年の「改変歴史教科書」とSNS投稿文が手に入ります

**文明崩壊**：人口・技術・秩序のいずれかが **0以下または100以上** になるとゲームオーバー。
歪みは時代錯誤の度合いで、高まると島にグリッチや時空の裂け目が現れます。

## Gemini API（任意）

- タイトルまたはパネルの ⚙ から APIキーを設定（ブラウザの `localStorage` にのみ保存）
- モデル: `gemini-3.8-flash`（設定画面で変更可）、`responseMimeType: "application/json"` で歴史テキスト・パラメータ増減・箱庭の描画指示を受け取ります
- キー未設定時・「オフライン」スイッチON時・通信失敗時は、内蔵のオフライン予言エンジンで遊べます

## 公開（GitHub Pages）

ビルド不要のバニラ構成です。リポジトリの Settings → Pages で `main` ブランチのルート（`/`）を公開するだけで動作します。

```
index.html        画面構成（Tailwind CSS CDN + Google Fonts DotGothic16 / Press Start 2P）
css/style.css     ドット・石板・メタル調スタイル
js/config.js      コース・時代・単語プール・建物定義
js/sprites.js     建物のプロシージャル・ドット絵
js/iso-map.js     浮島の地形生成・アイソメトリック描画・住人・天候・演出
js/oracle.js      Gemini API 通信とオフライン予言エンジン
js/logo.js        ドット絵ロゴ
js/sfx.js         WebAudio 効果音
js/main.js        ゲーム進行・UI
```

ローカルで試す場合は `python3 -m http.server` などで配信して `http://localhost:8000/` を開いてください（`index.html` を直接開いても動作します）。
