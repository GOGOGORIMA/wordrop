# WORDROP — 歴史改変シミュレーション

空に浮かぶ 100×100 タイルの箱庭の島に「単語」を投下して、歴史を書き換えるブラウザゲームです。
90年代のクォータービュー箱庭ゲーム風の見た目を、外部画像を使わずすべて Canvas のプロシージャル描画で表現しています。

## 遊び方

1. タイトルで **PUSH START BUTTON** → モードを選択（**全歴史モード**＝全50時代から抽選／日本史モード／世界史モード）。セーブがあれば **続きから再開** も選べる
2. ランダムに提示される3つの時代カードから、舞台となる時代を1つ選ぶ（1回だけ「引き直し」可）。時代は途中で変わらない
3. 選んだ時代の開始年1月から、**時計がリアルタイムに進む**。100年を1チャプター（1世紀）として進行
   - 等倍（×1）で **5秒＝1ヶ月 / 60秒＝1年**。`⏸ 一時停止` `▶ ×1` `▶▶ ×2 (30秒/年)` `▶▶▶ ×4 (15秒/年)` で速度を変更し、`⏭ 次の歴史イベント年までスキップ` で待ち時間を飛ばせる（キーボード：Space／1・2・4／S）
   - 月ごとに浮島の色味が春夏秋冬で変わり、神託の影響が流れていない間は2〜3年おきに時代背景やパラメータに応じた日常の小さな出来事が起きる
   - 時間とともに島は自然に発展する：人口に応じて田畑・水田が広がり（季節で稲の色が変わる）、技術と秩序に応じて土の道→石畳→舗装道路と橋が伸び、時代相応の住まい（竪穴住居／民家・長屋・櫓／レンガ造り／ビル）が建ち、馬・荷車・人力車・馬車・帆船・蒸気機関車などが行き交う
   - 浮島はキャンバスいっぱいに自動フィット。マウスホイール／ドラッグ（スマホはピンチ／スワイプ）や右上の ＋ － ⟲ で拡大・縮小・移動できる（ダブルクリックで全体表示）
4. 単語（15文字以内）を **神託として投下**できるのは **100年につき3回まで**（`残り神託：★★★`）。さらに1回投下すると **ゲーム内で15年間はクールタイム** で、入力欄・ボタン・カードがロックされ「次の神託解禁まで：あと X 年（〇〇年）」と充填バーが表示される
   - 投下した瞬間に「〇〇年〇月、空から『野球』の概念が降り注いだ――」と物語が始まり、Gemini（またはオフライン予言）が裏側で15年間のタイムラインを1回の通信で生成する
     - 🏛️ 歴史の変容：投下直後から1〜3年おきに、社会が単語に侵食されていく様子（出現と誤解→流行→摩擦→副作用→魔改造→制度化→世代交代→定着→長期余波）
     - ✴️ オーパーツ：投下から1・4・8・12年後、単語から連想される **時代背景を完全に無視した突然変異** が島に出現（ナイター照明付き球場／ガラス張りの高層ビル街／コンビニ・タピオカ屋・ネオン街・自販機／高架線路と走り回る新幹線／アスファルト道路と自動車・トラック／電波塔・パラボラ・ソーラー／コンビナート・原子炉／観覧車・黄金の巨像）
     - 💬 市井のざわめき：4〜6ヶ月おきに庶民・兵士・貴族の日常の小事件が流れ、浮島の住人の頭上にドット風の吹き出しが浮かぶ
   - ログには予定表やシステム用語は一切出さず、その年月に実際に起きた出来事と人々の反応だけを、新しいものから物語として表示する。クールタイムバーの横には現在の侵食フェーズを表示。複数の神託の影響は並行して進む
5. **史実の大事件**：各時代の開始から100年の間に、年号どおりに3〜4件の史実（例：戦国末期なら1575年 長篠の戦い／1582年 本能寺の変／1600年 関ヶ原の戦い／1637年 島原の乱）が割り込んでくる
   - 時計の下に「次の史実イベント：〇〇年『事件名』まであと Y 年」を常時表示
   - その年月に到達すると赤い警報とともに「⚠️ 史実イベント割り込み発生！」。それまでに投下した単語と現在のパラメータによって史実がどう狂ったかを Gemini（またはオフライン判定）が決め、ログ・パラメータの大幅変動・浮島の変化として発動する
6. 100年ごとに時間が止まり **「百年史の到達点」** が開く。この100年の神託と文明の変化を振り返り、
   - **ここで歴史を確定して完了する** → 改変された歴史教科書カード＆SNSシェアへ
   - **101年目以降もこのまま継続する** → 浮島・パラメータ・歴史を引き継ぎ、神託が★★★に回復して次の100年へ（何世紀でも続けられる）
7. 文明が崩壊すると、崩壊直後の空撮と経緯をまとめた「時空省・滅亡調査報告書」が発行される
8. どちらの結果も、文章のコピー・Xへの投稿に加えて、教科書／報告書と空撮を1枚にまとめたPNG画像（1200×675）を保存・コピー（対応端末では画像付き共有）できる

**オートセーブ**：ゲーム内で年が変わるたび、神託の投下時、百年史の到達点、タブを閉じる・隠すときに `localStorage` へ自動保存します（年月・パラメータ・浮島の地形と建物・表示位置・神託の履歴・クールタイム・予約イベント・市井のざわめき・オーパーツ・田畑や道路や線路・史実イベントの進行・ログ）。リロード後はタイトルの「続きから再開」で一時停止状態から再開できます。

**文明崩壊**：人口・技術・秩序のいずれかが **0以下または100以上** になるとゲームオーバー。
歪みは時代錯誤の度合いで、高まると島にグリッチや時空の裂け目が現れます。

全50時代のデータ（時代名・開始年・地域・背景・補正値・バイオーム・固有要素・シンボル建築）は `js/eras.js` に、時間の速さ・1チャプターの年数・神託の回数とクールタイム・10段階の変容イベントと市井のざわめきの間隔は `js/config.js` に定義しています。

## Gemini API（任意）

- タイトルまたはパネルの ⚙ から APIキーを設定（ブラウザの `localStorage` にのみ保存）
- モデル: `gemini-3.8-flash`（設定画面で変更可）、`responseMimeType: "application/json"` で年次タイムライン（各年の出来事・パラメータ増減・箱庭の描画指示・市井のざわめき・オーパーツ `mutant_objects`）を受け取ります
- キー未設定時・「オフライン」スイッチON時・通信失敗時は、内蔵のオフライン予言エンジンで遊べます

## 公開（GitHub Pages）

ビルド不要のバニラ構成です。リポジトリの Settings → Pages で `main` ブランチのルート（`/`）を公開するだけで動作します。

```
index.html        画面構成（Tailwind CSS CDN + Google Fonts DotGothic16 / Press Start 2P）
css/style.css     ドット・石板・メタル調スタイル
js/config.js      モード・バイオーム・単語プール・建物定義
js/eras.js        全50時代データベースと抽選
js/history.js     各時代の史実の大事件（全50時代・172件）
js/sprites.js     建物のプロシージャル・ドット絵
js/iso-map.js     浮島の地形生成・アイソメトリック描画・住人・天候・演出
js/oracle.js      Gemini API 通信とオフライン予言エンジン
js/share-image.js 結果カード（教科書／滅亡報告書＋空撮）のPNG書き出し
js/logo.js        ドット絵ロゴ
js/sfx.js         WebAudio 効果音
js/main.js        ゲーム進行・UI
```

ローカルで試す場合は `python3 -m http.server` などで配信して `http://localhost:8000/` を開いてください（`index.html` を直接開いても動作します）。
