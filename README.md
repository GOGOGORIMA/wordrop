# WORDROP — 歴史改変シミュレーション

空に浮かぶ 100×100 タイルの島に「単語（神託）」を投下し、100年の歴史を AI（Gemini）に書き換えさせるブラウザゲームです。
外部画像は使わず、島・建物・乗り物・住人はすべて Canvas のプログラム描画です。

## 遊び方

1. タイトル画面（星空に浮かぶ島）で `▶ NEW GAME` を押し、全50時代（日本史・世界史）からランダムに提示される3つのうち1つを選ぶと、その時代の開始年1月から時間が動き出す（途中で時代は変わらない）。遊びたい時代がなければ `🎲 別の時代を引き直す` で何度でも別の3つを再抽選できる
2. 時間はリアルタイムに進む：×1 で **60秒＝1年（5秒＝1ヶ月）**。ヘッダーの `⏸` `▶×1` `▶▶×2` `▶▶▶×4` で速度を変え、`⏭` で次のイベントの年までスキップ（キーボード：Space で一時停止、S でスキップ）
3. 単語（15文字以内）を投下できるのは **100年に3回まで**。1回投下すると **15年間ロック** され、「次の神託まで あと〇年〇ヶ月」とカウントダウンだけが表示される
4. 投下すると Gemini が1回の通信で次の3つを生成し、タイマーにセットする
   - 年次のメイン歴史変容イベント（9件・投下直後〜30年後。実在の人物・物理現象・社会崩壊）
   - 数ヶ月おきに流れる市井の小ログと住人の吹き出し（12件）
   - 島のど真ん中に出現するオーパーツ（ドーム球場／高層ビル／コンビニ／新幹線／高速道路と車／巨大工場／電波塔）
5. 各時代には実際の年号どおりの **史実の大事件** が3〜4件あり、その年月に達すると、投下済みの単語との化学反応で史実がどう歪んだかを Gemini が判定する
6. 100年たつと「ここで歴史を確定（2026年の歴史教科書カード）」か「神託を3つ回復して次の100年へ」を選べる
7. 人口・技術・秩序のどれかが **0以下か100以上** になると文明崩壊。Gemini が「時空省 滅亡調査報告書」を書く。4つ目のパラメータ「歪み」は時代錯誤の度合いで、崩壊には関係しないが、高まると島に時空のグリッチが走る
8. 教科書・報告書は、空撮付きの PNG 画像（1200×675）として保存でき、X へのシェア文も付く

**オートセーブ**：毎年1月、神託の結果を受け取った直後、史実イベントの直後（ほかに「タイトルへ戻る」やタブを閉じるとき）に、時代・年月・4つのパラメータ・神託の残り回数とクールタイム・予約された AI イベント・ログ・浮島の配置を `localStorage`（キー `wordrop_autosave_v1`）へ保存し、ヘッダーに `💾 AUTO SAVED` が一瞬光る。タイトルの `⏯ CONTINUE` で保存した時点から再開できる。文明崩壊、または100年で歴史を確定するとセーブは消える。

島は時間とともに時代相応に発展する（人口に応じて民家と田畑が増え、技術に応じて土の道→石畳→舗装路になり、住人が歩き回る）。季節ごとに色が変わる。マウスホイール・ドラッグ（スマホはピンチ・スワイプ）や右下の ＋ － ⟲ でズームと移動ができる。

## AI 通信

- プレイヤーは何も設定しません。すべての AI 通信（神託のタイムライン、史実イベント、教科書、滅亡報告書）は、最初から自動で Cloudflare Workers（`https://wordrop-api.toheritu22.workers.dev/`）へ POST します。ボディは Gemini の `generateContent` と同じ形（`contents` と `generationConfig: { responseMimeType: "application/json" }`）です
- 返ってきた JSON は、Gemini 形式（`candidates`）でも本文の JSON そのものでも受け取り、```` ```json ```` のマークダウンが付いていれば取り除いてからゲームに反映します。通信先は `js/config.js` の `WD.ENDPOINT`
- 歴史の文章（ログ・吹き出し・史実の歪み・教科書・報告書）は **すべて AI の生成** で、ローカルの定型文やデモ文は一切ありません
- 通信や応答に問題があれば、時間を止めたままエラーモーダルで原因（HTTP ステータスと応答本文、通信不能・CORS、タイムアウト、JSON 解析失敗、件数不足、生成拒否）を表示し、`↻ 再試行` か中止（神託なら取り消して回数は減らない）を選べます

## ファイル構成

ビルド不要のバニラ JS です。GitHub Pages の Settings → Pages で `main` ブランチのルートを公開すれば動きます。

```
index.html      画面の構造
css/style.css   レイアウト（PC：100vw×100vh の2カラム／スマホ：38vh＋62vh の縦1カラム）
js/config.js    定数（時間の速さ・神託の回数・パラメータ・通信先・セーブのキー・オーパーツの種類）
js/data.js      全50時代と史実の大事件（172件）
js/ai.js        Gemini 通信・プロンプト・応答の検証・エラー
js/sprites.js   建物・乗り物のドット絵
js/island.js    浮島の生成・描画・カメラ・自然な発展・住人・オーパーツ・吹き出し
js/card.js      結果カードの PNG
js/game.js      タイトル・時代の選択・ゲーム進行（状態・時間のループ・出来事のキュー）・オートセーブ・画面
```

ゲームの状態は `game.js` の `S` ひとつにまとまっています。時間は `requestAnimationFrame` のループひとつで進み、起きることはすべて「何ヶ月目に何が起きるか」のキュー `S.queue` に入れて順に発火します。モーダルや AI 通信の待ちは `holds` に理由を入れて表し、`holds` が空でないあいだは時間が止まります。

ローカルで試すときは `python3 -m http.server` などで配信して `http://localhost:8000/` を開いてください。
